section · 1

Why HTML, why now

The "HTML is the new Markdown for LLM I/O" thesis crystallized in May 2026 after Thariq Shihipar's Unreasonable Effectiveness of HTML and Simon Willison's permalink endorsement. The defensible reading isn't "HTML beats Markdown everywhere" — it's bifurcated by direction:

DirectionBest formatWhy
Agent → human (outputs, decisions, artifacts)HTMLDiagrams, tables, hierarchy, links, interactivity — Markdown flattens all of it.
Agent → agent (context, retrieval, RAG)HTML with structured data islandsHtmlRAG (Tan et al., Nov 2024) shows HTML beats plain-text on six QA benchmarks because heading and table structure survive.
System → agent (tables, configs)Markdown-KV or YAMLImproving Agents 2025 benchmarks show MD-KV at 60.7 % vs HTML at 53.6 % on tabular tasks.

htmem is built for the first two. For the third (config files, table input), keep using Markdown.

section · 2

Install

1. Add the marketplace

/plugin marketplace add droggy992/htmem@v0.1.0

Always pin by tag, never bare main. The plugin code runs on your machine; you should be able to read every line you're trusting.

2. Install the plugin

/plugin install htmem@htmem-plugins --scope user

User scope writes to ~/.claude/settings.json.

3. Create your first memory

/htm-new memory "Why we picked Redis"

Claude scaffolds, fills in body, anchors with SHA-256.

4. View it safely in a browser

/htm-render htmem/memory-why-we-picked-redis-2026-05-15.html

Opens via a CSP-hardened localhost server inside a sandboxed iframe.

section · 3

Architecture — one file, two pipelines

A single htmem file feeds two physically separate pipelines: one for LLMs (sanitize + verify + sentinel-wrap), one for humans (CSP-hardened iframe sandbox). They never share rendering code, so a bypass in one pipeline can't compromise the other. This is a direct response to CamoLeak (CVE-2025-59145) and CVE-2026-22813.

section · 5

What ships in v0.1.0

4 skills

htmem-write · htmem-read · htmem-render · htmem-audit. Narrow auto-trigger only on explicit /htm-*, literal "htmem", or referenced paths.

5 slash commands

/htm-new · /htm-read · /htm-render · /htm-audit · /htm-hub. Each enforces $ARGUMENTS single-quoting and refuses shell metachars.

3 HTML templates

memory · decision · thread. Modern CSS (@layer, light-dark()). Inert JSON / JSON-LD / text-plain data islands. No JS.

5 JSON schemas

memory · decision · thread · identity · llm-onboarding. $defs.safeText rejects BMP zero-width / RTL-override / format / BOM chars.

8 Python scripts

anchor · sanitize · schema_validator · validate · read_memory · audit · new_memory · render_server. Python 3.10+ stdlib only.

1 MCP server

Stdio JSON-RPC bridge. Exposes htmem://<path> resources + htmem_read / htmem_audit / htmem_list tools.

Opt-in hooks

hooks/hooks.json ships empty. Three vetted recipes: PostToolUse snapshot · SessionStart digest · PreToolUse signed-decision gate.

2 regression tests

G01 forged-manifest-under-dropped-subtree (7 vectors) · V18 multi-manifest-smuggling. Stdlib only, wired into CI.

CI stack

gitleaks · CodeQL · Semgrep (OWASP Top 10 + python + security-audit) · trufflehog · plugin-validate · end-to-end smoke + regression tests. Dependabot weekly.
